# 📚 Meu Top Livros

Uma página desenvolvida com **HTML5** e **CSS3** apresentando uma lista dos livros que mais marcaram minha vida.

O objetivo deste projeto é praticar conceitos básicos de desenvolvimento web, como estruturação semântica, estilização com CSS e organização de layout utilizando Flexbox.

## 🚀 Demonstração

> Em breve disponível no GitHub Pages.

## ✨ Funcionalidades

- 📖 Lista dos meus livros favoritos.
- 🖼️ Capa de cada livro.
- ✍️ Nome do autor.
- 💬 Trechos marcantes de cada obra.
- 🔢 Numeração automática dos livros com CSS Counter.
- 📑 Barra lateral com informações adicionais.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
